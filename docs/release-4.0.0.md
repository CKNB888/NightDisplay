# NightDisplay 4.0.0

Rust 重写；只保留 Windows。核心变化：**默认走虚拟屏，本机真黑，远程画面不冻、不闪。**

## 下载

| 文件 | 适合谁 |
|---|---|
| `NightDisplay-4.0.0-Setup.exe` | 大多数人。装到当前用户目录，**不需要管理员**；驱动安装由程序里的向导负责，全程只弹一次 UAC |
| `NightDisplay-4.0.0-portable.zip` | 想放 U 盘、不装东西的人。解压即用，`resources\vdd` 里带着驱动 |
| `SHA256SUMS.txt` | 校验用 |

系统要求：**Windows 10 2004（build 19041）及以上，x64**。需要系统自带的 WebView2
（Win11 全都有；Win10 若没有，装一次微软的 Evergreen Runtime）。

## 这版做了什么

### 1. 黑屏方式变了：虚拟屏优先，不再靠"盖一层窗口"

* **默认模式 `virtual_screen`**：把桌面交给随包的虚拟显示驱动，实体屏保留在显示配置里
  但不接桌面。本机看到的是真黑（显示器没有输出），远程软件抓着的那块采集表面
  **一直活着**，所以**不冻、不闪**。
* 整个切换是**一次** `SetDisplayConfig`：先 `SDC_VALIDATE` 校验，不过就什么都不改；
  过了再一次 `SDC_APPLY`。切换后活动 target 数永远 ≥ 1。
* 虚拟屏在常驻进程启动时就"预热"好（克隆进桌面但不接管），入夜只改一个标志位。
* 驱动不行时**自动降级**到黑幕模式（`overlay`：采集排除的黑幕 + gamma + 背光），
  并在界面写清楚为什么降级。
* `screen_off` 保留为手动选项，界面标着"动鼠标会亮"。

### 2. 首次运行向导：一次 UAC，六个步骤，每步都给真实结果

授权并准备后台服务 → 虚拟显示驱动（**必需**，装完必须能在显示配置里看到虚拟屏）→
开机自启与看门狗 → 本地防触控与锁屏 → 15 秒真实自检 → 勾选「已确认远程能连」。
任何一步失败都给出确切的手动命令或链接；设置里的「重新授权 / 修复」只重跑失败的那几步。

### 3. 三条自启路径 + 看门狗 + 崩溃恢复

HKCU `Run`、登录计划任务、SYSTEM 权限的开机计划任务（延迟 30 秒，没人登录也能进夜间）
同时登记，单实例锁让它们互相幂等。用户自己关掉自启后，程序**不会**再把它加回来。
关机/注销前先还原 gamma、背光和拓扑；进程被强杀时独立看门狗在几秒内接手。

### 4. 全新界面（Tauri 2 + WebView2）

深色侧边栏（首页 / 定时计划 / 显示模式 / 运行日志 / 设置 / 关于），首页有倒计时环，
自定义开关，托盘菜单（立即黑屏 / 恢复 / 暂停 / 打开设置 / 退出），关窗进托盘。
窗口大小位置记住，100%–200% 缩放都清晰。界面**永远不以管理员身份运行**。

### 5. 诊断

* 「运行日志 → 夜间会话」：上一次夜间每一步（预热、拓扑、模式匹配、落定、活动路径、
  gamma、背光、防触控、锁屏、恢复）的耗时和真实结果，失败和跳过分开显示；
* 「导出诊断包」：一个 zip，含按组件分开的日志、脱敏后的配置、自检 JSON、
  显示器/DDC 报告、Windows 与显卡驱动版本、最近 5 次会话摘要。
  不含远程账号、不含桌面内容。
* `--action selfcheck` 打印 JSON + 中文摘要；`--debug` 提高日志级别。

## 从 3.x 升级

直接装新的就行，数据目录不变（`%LOCALAPPDATA%\NightDisplay`），计划和开关都会读进来。
第一次打开会让你走一遍向导（3.x 的配置里没有新版的授权记录）。

## 已知限制（请先读完再判断适不适合你）

* **不是所有显卡组合都能做到零闪**。下面这些情况仍然可能有一帧黑：
  驱动在 `SDC_APPLY` 内部重初始化输出（部分老 Intel 核显 + HDMI 外接）、
  实体屏和虚拟屏刷新率无法同时满足、多显卡跨适配器路径集被驱动拒绝、
  系统里已有第三方虚拟屏且命中匹配规则。程序保证的是"一次提交、不产生零 target、
  校验不过就什么都不改"，不保证每一台机器的驱动都配合。
* **DDC/CI 背光**在一体机和部分笔记本内屏上不可用。这类机器夜间是纯黑但背光仍亮，
  自检会点名是哪块屏。
* 采集排除的黑幕只在 Win10 2004+ 可用；系统接受了请求不等于每种远程采集方式都兼容。
* 断电、强制关机时看门狗也活不了，下次启动才恢复。
* **CI 没有在真实一体机上验证过**，也没法在 CI 里验证远程会话。没跑过的机型和远程软件，
  不标注为"已保证兼容"。

有问题请附上「设置 → 导出诊断包」的 zip（已脱敏）和远程软件名称、显卡型号。
