    显示模式

    决定「黑屏」具体怎么做。默认用虚拟屏，切不过去会自动降级并如实告诉你。

    这台机器的能力

    虚拟屏模式需要内置驱动（安装向导里装）。它把桌面交给一块虚拟显示器， 实体屏保持点亮但不带桌面 —— 远程软件看到的是虚拟屏上的桌面，不会黑。

    设置

    所有改动都会立刻落到配置里；需要写系统计划的任务会先写系统、成功了才保存。

    启动与后台

    开机自启

    同时登记 Run 键、登录计划和开机计划三条路径，断电重启后也能起来。

    本地防触控

    夜间吞掉本机键鼠

    远程软件注入的操作照常放行；本机实体键盘鼠标被忽略，避免把黑幕点掉。

    夜间抑制系统锁屏

    不抑制的话，锁屏界面会盖在黑幕上，远程可能看到登录画面。

    解锁组合键

    夜间按住这个组合键可以立刻恢复显示，并且本段剩余时间不再黑屏。

    夜间行为

    夜间阻止睡眠

    远程长时间不操作时，机器不会睡过去。

    夜间使用高性能电源计划

    白天恢复成原来的电源计划。

    设计取舍

    • 界面不提权。装驱动、写计划任务都交给一个常驻的提升助手，界面本身永远是普通权限。
    • 引擎不在界面里。关掉窗口不会影响今晚的黑屏；界面只是它的遥控器。
    • 三条自启路径。断电重启、强杀进程之后也能自己恢复，看门狗兜底。
    • 失败要说清楚。每一步都给出真实结果：成功 / 跳过 / 需要手动处理（带命令）。

    安装向导

    只弹一次管理员确认，之后夜间切换不再打扰。
